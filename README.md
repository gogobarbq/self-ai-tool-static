- 預覽使用 Median 的 `.nB` / `.pE` 結構。
- 新增 ☀ Light / 🌙 Dark 切換；Dark 使用 Theme 本身的 `data-theme="dark"` 規則。
- Workbench 只提供預覽容器寬度與外圍留白，不干預文章元素樣式。
