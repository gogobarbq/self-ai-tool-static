# NC Blogger Toolkit v1.0

## blogger-theme-workbench.html
Theme Workbench v2.7

新增：
- 所有「未設定／未辨識」的文章外觀欄位都可直接輸入值。
- select 類型保留選單，也允許保持未設定。
- color / background-color 類型提供色碼欄位與 color picker。
- 「恢復載入 Theme 時的值」可撤銷本次自訂。
- Quote 預覽不再自帶假灰底。
- 若 `blockquote` 原本沒有 `background-color`，現在可直接新增。
- 保留 Accordion 與 YouTube iframe Theme 支援。
